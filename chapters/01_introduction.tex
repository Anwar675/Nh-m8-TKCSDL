\chapter{GIỚI THIỆU}

\section{Lý do chọn đề tài}

Trong thời đại công nghệ số, các nền tảng streaming phim trực tuyến như Netflix, HBO Go, Disney+ đang trở nên phổ biến. Việc xây dựng một cơ sở dữ liệu hiệu quả là nền tảng cho sự phát triển của các hệ thống này.

\section{Mục tiêu của đồ án}

\subsection{Mục tiêu tổng quát}
Thiết kế cơ sở dữ liệu cho hệ thống FilmLab, đáp ứng các yêu cầu nghiệp vụ cốt lõi.

\subsection{Mục tiêu cụ thể}
\begin{enumerate}
    \item Phân tích yêu cầu của hệ thống FilmLab
    \item Xây dựng mô hình ERD ở mức khái niệm
    \item Chuyển đổi sang mô hình quan hệ ở mức logic
    \item Thiết kế mức vật lý trên PostgreSQL
    \item Tạo từ điển dữ liệu chi tiết
    \item Viết các truy vấn SQL mẫu
\end{enumerate}

\section{Phạm vi và giới hạn}

\subsection{Phạm vi}
\begin{itemize}
    \item Quản lý phim: Thông tin phim, thể loại, diễn viên, đạo diễn
    \item Quản lý người dùng: Đăng ký, đăng nhập, gói đăng ký
    \item Quản lý hoạt động: Xem phim, đánh giá, bình luận
    \item Quản lý danh sách yêu thích
    \item Lịch sử xem phim
\end{itemize}

\subsection{Giới hạn}
\begin{itemize}
    \item Không xây dựng ứng dụng thực tế (chỉ thiết kế CSDL)
    \item Không triển khai trên server thực (chỉ thiết kế)
    \item Không bao gồm các tính năng thanh toán phức tạp
\end{itemize}

\section{Phương pháp thực hiện}

\begin{enumerate}
    \item Thu thập và phân tích yêu cầu
    \item Thiết kế mức khái niệm (ERD)
    \item Thiết kế mức logic (Chuẩn hóa 3NF)
    \item Thiết kế mức vật lý (PostgreSQL)
    \item Viết SQL scripts và truy vấn mẫu
    \item Hoàn thiện tài liệu
\end{enumerate}

\section{Cấu trúc đồ án}

Đồ án gồm 9 chương:
\begin{enumerate}
    \item Giới thiệu
    \item Phân tích yêu cầu
    \item Thiết kế mức khái niệm
    \item Thiết kế mức logic
    \item Thiết kế mức vật lý
    \item Từ điển dữ liệu
    \item SQL Scripts
    \item Truy vấn mẫu
    \item Kết luận
\end{enumerate}
