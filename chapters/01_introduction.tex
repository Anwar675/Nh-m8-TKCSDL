\chapter{GIỚI THIỆU}

\section{Mục tiêu của đồ án}

\subsection{Mục tiêu tổng quát}
Thiết kế cơ sở dữ liệu PostgreSQL nhất quán, bảo toàn dữ liệu và đáp ứng các luồng nghiệp vụ cốt lõi của nền tảng FilmLab.

\subsection{Mục tiêu cụ thể}
\begin{enumerate}
    \item Phân tích tác nhân, yêu cầu chức năng, phi chức năng và các Core Flow.
    \item Xây dựng ERD tổng thể và xác định cardinality giữa các thực thể.
    \item Chuyển mô hình khái niệm sang mô hình quan hệ, chuẩn hóa tối thiểu đến 3NF.
    \item Thiết kế vật lý trên PostgreSQL với constraint, index, audit và soft-delete.
    \item Xây dựng Data Dictionary, script SQL và truy vấn mẫu kiểm chứng nghiệp vụ.
    \item Chuẩn bị cấu trúc dữ liệu có thể mở rộng cho tìm kiếm, gợi ý và trợ lý AI.
\end{enumerate}

\section{Phạm vi và giới hạn}

Phạm vi dữ liệu gồm người dùng và RBAC; Film Lab và dịch vụ; đơn hàng và vòng đời xử lý phim; giao nhận và thanh toán; kho ảnh phim số; marketplace; knowledge/community; notification và dữ liệu hỗ trợ AI.

Đồ án chỉ tập trung thiết kế cơ sở dữ liệu, không triển khai đầy đủ giao diện, API hay mô hình AI. File ảnh dung lượng lớn được lưu tại cloud object storage; cơ sở dữ liệu quản lý URI và metadata. Tích hợp thanh toán, vận chuyển và AI được mô hình hóa ở mức dữ liệu.

\section{Phương pháp thực hiện}

Quy trình gồm phân tích yêu cầu, thiết kế khái niệm, thiết kế logic và chuẩn hóa, thiết kế vật lý PostgreSQL, xây dựng Data Dictionary và SQL, sau đó kiểm chứng bằng truy vấn theo Core Flow. Thiết kế được cross-review theo module để phát hiện quan hệ thiếu và ràng buộc không nhất quán.

\section{Cấu trúc báo cáo}

Báo cáo gồm chín chương: giới thiệu; phân tích yêu cầu; thiết kế khái niệm; thiết kế logic; thiết kế vật lý; từ điển dữ liệu; kịch bản SQL; truy vấn mẫu; và kết luận.
