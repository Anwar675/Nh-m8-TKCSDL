\chapter*{TÓM TẮT ĐỒ ÁN}
\addcontentsline{toc}{chapter}{TÓM TẮT ĐỒ ÁN}

Đồ án này tập trung vào việc thiết kế cơ sở dữ liệu cho hệ thống \textbf{FilmLab} - một nền tảng quản lý và phân phối phim trực tuyến.

\section*{Mục tiêu}
Xây dựng một cơ sở dữ liệu quan hệ hoàn chỉnh cho FilmLab, bao gồm:
\begin{itemize}
    \item Thiết kế mức khái niệm (ERD)
    \item Thiết kế mức logic (chuẩn hóa đến 3NF)
    \item Thiết kế mức vật lý trên PostgreSQL
    \item Xây dựng từ điển dữ liệu chi tiết
    \item Viết các truy vấn SQL cho nghiệp vụ cốt lõi
\end{itemize}

\section*{Phạm vi}
Hệ thống quản lý các đối tượng:
\begin{itemize}
    \item Quản lý phim, diễn viên, đạo diễn, thể loại
    \item Quản lý người dùng và gói đăng ký
    \item Quản lý đánh giá, bình luận
    \item Quản lý lịch sử xem phim
    \item Quản lý danh sách yêu thích
\end{itemize}

\section*{Kết quả đạt được}
\begin{itemize}
    \item Mô hình ERD với 12+ thực thể và các mối quan hệ
    \item 12 bảng trong cơ sở dữ liệu được chuẩn hóa 3NF
    \item 20+ truy vấn SQL cho các nghiệp vụ chính
    \item Tài liệu thiết kế đầy đủ 9 chương
\end{itemize}

\section*{Công nghệ sử dụng}
\begin{itemize}
    \item \textbf{DBMS:} PostgreSQL 15+
    \item \textbf{Ngôn ngữ:} SQL, \LaTeX
\end{itemize}

\textbf{Từ khóa:} FilmLab, Cơ sở dữ liệu, ERD, PostgreSQL, Thiết kế CSDL, SQL.
